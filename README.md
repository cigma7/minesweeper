# 지뢰 찾기

윈도우 고전 지뢰 찾기를 휴대폰 브라우저에서 할 수 있게 다시 만든 웹앱입니다.

**주소: https://cigma7.github.io/minesweeper/**

## 아이폰 홈 화면에 추가하기

1. Safari로 위 주소를 엽니다.
2. 아래쪽 공유 버튼(네모에 위쪽 화살표)을 누릅니다.
3. **홈 화면에 추가**를 누릅니다.

한 번 추가하면 아이콘으로 바로 실행되고, 인터넷이 없어도 됩니다.

## 조작

| 동작 | 결과 |
|---|---|
| 탭 | 칸 열기 |
| 길게 누르기 | 깃발 → 물음표 → 해제 |
| 숫자 칸 탭 | 깃발 수가 맞으면 주변 칸을 한꺼번에 열기 |
| 누른 채 밀기 | 누른 칸 옮기기, 손을 뗀 칸이 열림 |
| 스마일 | 새 게임 |
| 메뉴 (지뢰 수 왼쪽) | 난이도 · 칸 크기 · 설정 · 최고 기록 · 도움말 |

## 판 크기와 난이도

판은 원본 크기(9×9, 16×16, 30×16)를 따르지 않고 **휴대폰 화면에 꽉 차게** 만듭니다. 칸이 작아지지 않도록 칸 크기를 먼저 정하고, 그 크기로 들어가는 만큼 판을 채웁니다.

| 칸 크기 | 한 변 최소 | 일반 아이폰(13~16) 세로 화면 |
|---|---|---|
| 큰 칸 | 43 | 가로 8 × 세로 15 |
| 보통 칸 (기본) | 38 | 가로 9 × 세로 17 |
| 작은 칸 | 34 | 가로 10 × 세로 19 |

난이도는 지뢰 비율로만 나눕니다. 앞의 셋은 원본 초급·중급·고급의 비율과 같습니다.

| 쉬움 | 보통 | 어려움 | 아주 어려움 |
|---|---|---|---|
| 12% | 16% | 21% | 25% |

- 판 모양은 세로 화면 기준입니다. 가로로 눕히면 같은 판을 돌려서 보여줍니다.
- 최고 기록은 난이도와 칸 크기 조합마다 따로 남습니다.

## 원본과 같은 점

- 첫 칸은 절대 지뢰가 아님 (걸리면 그 지뢰를 왼쪽 위 첫 빈칸으로 옮김)
- 연쇄 열기, 숫자 칸 동시 열기, 물음표 표시 켜기/끄기, 색(흑백), 소리
- 지면 밟은 지뢰는 빨간 바탕, 잘못 꽂은 깃발은 X 표시, 이기면 남은 지뢰에 깃발

## 파일

- `engine.js` — 게임 규칙 (화면과 무관)
- `app.js` · `style.css` · `index.html` — 화면과 조작
- `sw.js` · `manifest.webmanifest` — 홈 화면 앱·오프라인 실행
- `tests/engine.test.js` — 규칙 검사 (`node --test tests/engine.test.js`)
